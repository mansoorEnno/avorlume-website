# Avorlume public portfolio

Public website for Mansoor Ijaz at https://avorlume.com, deployed from main through GitHub Pages.

## Build

Use Node 22 and pnpm 11.25.0. Run pnpm install --frozen-lockfile, then pnpm build. The dist folder contains pre-rendered public pages and their interactive React bundle. The existing CNAME is preserved.
