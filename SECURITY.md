# Reporting a security concern

Report security concerns affecting https://avorlume.com to hello@avorlume.com.

Include the affected URL, an explanation and minimal steps to reproduce the issue. Do not send passwords, authentication tokens, customer records or other private information. Avoid publishing sensitive exploit details in a public issue.

This static portfolio does not provide visitor accounts or a checkout. Its project enquiry form uses FormSubmit, as disclosed on the form and in the privacy notice.

There is no published bug bounty or guaranteed response time. This policy does not authorize intrusive testing of third-party services or access to anyone else's data.
